## 缩放后末行空位：渲染快照问题（提交 5237c41，仅本地未推）

**现象**（用户描述）：排行榜页电脑端缩成手机宽度会出现网格空位，手机端从别的页面进入或刷新则正常；
手机端无空位时放大成电脑端，又出现空位。首页没有这个问题。

**根因**：网格条目数在**页面加载那一刻**按当时列数算好，之后只改 css 不改数据。
缩放到另一个断点后，列数变了而条目数没变 → `n % cols ≠ 0` → 末行空。
首页之所以正常，是因为 `home.js` 早就有自己的 resize 监听会重画。

**修法**：
- `ui/card.js` 新增 `YY.card.watchCols(fn)`：单个全局 resize 监听（160ms 防抖），
  **只在 `cols()` 真正变化时**回调，避免每像素 resize 都重排。
- 注册方：`home.js`（替换原有私有实现）、`rank.js`（`paintMore()`）、
  `detail.js`（相关推荐）、`my.js`（收藏格 + 建议位）。
- `rank.js` 的 `gridCols()` 改为直接 `return YY.card.cols()`，**不再自己写一套断点**。

**踩到的坑（重要）**：
1. `.rank-grid` 的列数断点原来是 900，而 `.grid` 是 720 → 721~900 区间两边判断不同，
   `watchCols` 不触发。已把 `.rank-grid` 改成 1080/720/460，与 `.grid` 一致。
2. **CSS 同权重后者胜**：三条列数规则必须按 1080 → 720 → 460 的降序排在文件末尾。
   一开始把 3 列的规则塞进文件中部的 `@media (max-width:720px)`，
   被文件末尾的 1080 块（repeat(4)）覆盖，720 以下仍是 4 列。
   排查方法：`getComputedStyle(el).gridTemplateColumns` 数实际列数，别只看媒体查询。
3. 编辑 `@media` 块时容易连带删掉下一个块的开头，改完要数一下 `{` 与 `}` 是否配平。

**验证**：1440→1080→900→768→721→720→620→500→461→460→390→1440 连续缩放，
排行卡片数 20/16/12/8 与列数 5/4/3/2 始终整除；首页 20/12/12/20；
详情与我的追漫 10/9/10/10。四页均无 JS 报错。

**副作用（已告知用户）**：排行榜在 721~900px 区间从 3 列变为 4 列，
因为断点向 `.grid` 看齐；卡片略小，但与其他页面一致。

## 全站网格统一（提交 135dd11，仅本地未推）

用户反馈"最近更新页也有空白、平板还是三列"，暴露出**每个页面各自写一套断点**的老问题。

- `card.grid` 的裁零头条件从「仅 ≤3 列」改为**任何列数**：
  平板 4 列时 10 部会剩 2 张，这个区间此前完全没覆盖。
- `updates.js` 此前只在渲染时算一次 `cardStep()`，没有 watchCols，
  所以桌面 20 张缩到 3 列会有 1 格空。已注册重画，并把 `shownOld`
  重置为新的 `cardStep()`（否则旧批次数仍不整除）。
- `filter.css` 的 `.cat-grid` 原来是「6 列基准 + 1180→5 + 1080→4 + 900→3 + 720→3」，
  收敛为 5 / 4 / 3 / 2（1080 / 720 / 460），与 `.grid` 完全一致。
- `category.js` 的 `PAGE_SIZE = 36` 改为 `pageSize() = 列数 × 6`
  （桌面 30 / 平板 24 / 手机 18 / 小屏 12），每页天然整行；
  末页仍可能不满，这是「列表到底」，不是 bug。

**现行唯一真相**：列数只由 `YY.card.cols()` 决定（5/4/3/2 对应 1080/720/460），
所有卡片网格的 CSS 必须跟它对齐，所有按列数算条目的页面必须注册 `watchCols`。

**副作用（已告知）**：分类页桌面 6 列→5 列，每页 36→30 部（总页数 17→20）；
详情/我的追漫在 4 列下 10→8 张。

## 分类页筛选区手机端收密度（提交 64545dc，仅本地未推）

- 问题：手机端筛选卡片高 **758px**，几乎占满一屏；标签 32px 高、左右内边距 18px，
  且每个分组标题独占一行。
- 修法（全部写在 `filter.css` 的 `≤720` 断点内，桌面数值一个没动）：
  · `.f-opt` 32→28px、padding 18→10px、字号 13→12px
  · `.f-row` 从 `grid-template-columns: 1fr`（标题独占一行）改回
    `40px minmax(0,1fr)` + `gap: 8px`，标题与标签同排
  · 行内边距 7→5px、`.f-opts` 间距 8→6px、卡片内边距 16/14/8 → 12/12/4
- 结果：390px 下整卡 758 → **445px**，“排序”行 5 个标签排成一行。
- 桌面 1440/1024 复核仍是 32px 标签、52px 标题列，未受影响的。
- **注意**：以后改 `.f-opt` 的尺寸只在 `≤720` 断点里覆盖，基础样式是桌面用的。
