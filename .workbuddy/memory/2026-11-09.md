## 详情页卡片：银色玻璃 + 3D 倾斜（参考 foreverblog.cn）

### 原站原理（home.js 的 bindCardGlare + home-v18.css）
- `pointermove` 取指针在卡片内的比例 `x/y`（0~1）：
  `rotateY = (x-0.5)*9`、`rotateX = -(y-0.5)*7`，`transformPerspective: 900`，
  GSAP `quickTo` duration 0.5 / power3 做阻尼。
- 同时写 `--gx/--gy`（百分比），加 `.gl-on`：
  `.gl { background: radial-gradient(circle at var(--gx) var(--gy), var(--glass-fill), transparent 52%) }`
- 银边 = `.im { padding:6px; background:var(--glass-fill); box-shadow: inset 0 0 0 1px var(--glass-edge) }`
  浅色主题 `--glass-fill: rgba(255,255,255,.5)` / `--glass-edge: rgba(255,255,255,.8)`。

### 本项目实现
- `public/js/ui/tilt.js`（新）：不引 GSAP，rAF 指数逼近（`EASE=0.12`，约 0.4s 追平），
  角度 **MAX_RY 15 / MAX_RX 11**（原站 9/7 是按 300px 宽的卡调的，本站卡只有 200px，
  照搬几乎看不出来）。
  `pointerover` 委托到 document 逐张 attach（`el.__tiltOn` 标记），网格重渲染不会漏。
  只在 `body[data-page="detail"]` + `(hover:hover)` + 非 `prefers-reduced-motion` 下启用。
- `public/css/pages.css` 末尾 `body[data-page="detail"]` 一段：
  - `padding:7px` 装裱边，`168deg` 多段冷白渐变（#fff → #f2f4f8 → #fff → #dee2ea → #f4f6fa → #c6ccd6）
  - 四个方向的 inset 阴影造「上亮下暗」的金属厚度 + `0 0 0 1px rgba(20,22,28,.12)` 外描边
  - 光斑用**冷白** `rgba(214,231,255,.75)` + `mix-blend-mode: screen`
    （纯白压在暖色封面上会发黄，screen 只提亮不压暗，才像反光而不是白雾）
  - `.card { transition:none }`，角度由脚本逐帧写，再挂 0.28s 过渡会变拖影
  - `.card:hover { transform:none }`，否则和脚本写的 transform 互相覆盖

### 踩坑
- **纸色底（#f5f3ef）上白边框会糊成一张白纸**：必须有明确暗档和下边框暗线才立得起来。
- `:hover` 无法用 `dispatchEvent(new PointerEvent(...))` 触发 —— 光斑永远 opacity:0，
  会误判成「没生效」。给 `tools/shot.js` 加了 `--hover "选择器|横向比例|纵向比例"`，
  走 CDP 的 `Input.dispatchMouseEvent`（真鼠标），另外加了 `--dpr N` 看边框细节。
- 页面 `scroll-behavior: smooth`，`--eval` 里 `window.scrollTo` 是平滑滚动，
  紧接着算 rect 会算到旧位置（hover 到视口外）→ 先 `documentElement.style.scrollBehavior='auto'`。
- 倾斜角度别一次给太大：15/11 是上限，再大会让人晕，且卡片边缘会盖住邻居。

## 更正：银框 + 3D 倾斜要用在详情页「主封面」，不是相关推荐

用户截图圈的是详情页左侧那张大海报（`.detail-cover`），之前的实现加到了 `.card` 上，
已整段撤掉（底部相关推荐恢复原样）。

### 现在的做法
- 银框 = `.detail-cover` 自身 `padding: var(--frame)` + 金属渐变背景，img 缩在里面。
  `--frame`：桌面 10px、≤900 8px、≤720 6px（写在 responsive.css 对应断点）。
- 渐变**铺满整块画布**、只在边框那圈露出来，所以明暗必须压在首尾：
  竖直 `#fff → #f1f4f9 2% → #ccd3de 6% → #bec6d2 48% → #98a2b2 100%`，
  横向再压一道「左边提亮、右边压暗」。少了这一步 262px 的跨度走完，边框还是纯白一片。
- 四向 inset 阴影造厚度（上白线 / 下暗线 / 左右各一条），外圈 `0 0 0 1px rgba(255,255,255,.34)`。
- `::after` 在画面边缘画 1px 暗线 + 内侧阴影，画面才像「嵌」进框里。
- `::before` 冷白反光（`screen`），半径收到 96%、中心 0.55：
  原来 120%/0.8 会把人物脸洗白，像一层白雾。
- 倾斜：`MAX_RY 14 / MAX_RX 11`，`perspective 900`，`translate3d(0,0,18px)` 抬起（约放大 2%），
  `EASE 0.12`。最大角度下与右侧文字仍余 36px。

### 一个坑：不要用 getBoundingClientRect 算指针比例
卡片一边转、包围盒一边变——262 宽的卡转 5° 后包围盒宽了约 29px，
比例跟着漂，目标角度会自己抖。改用 `offsetParent.getBoundingClientRect() + el.offsetLeft/Top`
+ `offsetWidth/Height`，这套不受 transform 影响。

实测：连续移动 61fps（无头软件渲染），离开后 transform 清空、`is-tilt` 摘掉；
`prefers-reduced-motion` 下不启动，银框照常显示；手机 390/720 端框宽 6px 比例正常。
