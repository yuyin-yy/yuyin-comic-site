**CI**
- `.github/workflows/deploy.yml`：push main → rsync（`--delete` + 保护性 exclude）→ `npm ci --omit=dev`
  → `pm2 reload deploy/ecosystem.config.js --update-env`。
- 首个 guard 步骤检查 `SSH_HOST`/`SSH_KEY`，缺失时只打 notice 跳过，不把流水线跑红。
- rsync 的 `--exclude '.env' '.env.*' 'sql.env' 'node_modules' '.tmp' 'logs'` **同时是 --delete 的保护名单**，
  改同步参数时必须保留，否则会删掉服务器上的生产环境变量。
